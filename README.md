# PO Strategy — RSI 5s + Martingale

Simulateur web (Next.js) + extension navigateur (Lemur / Chrome) pour la stratégie RSI 5s confirmée par la mèche, avec 3 variantes de martingale et support multi-paires OTC.

## ⚠️ Avertissement

Outil éducatif uniquement. Les options binaires présentent un risque élevé de perte en capital. L'auto-trade en argent réel peut enfreindre les CGU de Pocket Option. **Utilise exclusivement en compte démo.**
